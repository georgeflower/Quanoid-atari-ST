# QUANOID

A native Atari ST breakout/Arkanoid-style game, built from scratch in 68000 C
and assembly for a real Atari 1040 STFM (developed and tested against
Hatari). It ports the level designs, bosses, power-ups, enemies and sound
effects from an earlier browser build ("Vibing Arkanoid") to real ST
hardware — no TOS-dependent timing, its own interrupt-driven input and sound.

## Status

Current shipped version: **V2.8**. Playable end to end: title screen, level
progression with brick layouts, paddle/ball physics, power-ups, enemies,
bosses, pause, high-score entry, and a level-complete/exit-door mechanic.

## Gameplay

- **Bricks**: standard, multi-hit (shown with pip dots for hits remaining),
  and indestructible.
- **Enemies**: cube, sphere and pyramid types that spawn during play (max 3
  on screen at once, replaced only once defeated or on level clear — no
  timeout), each colour-coded, with a "low HP" tint when nearly destroyed.
- **Bosses**: wireframe 3D bosses (cube / sphere / pyramid / hexagon "mega
  boss") with aimed shots, lasers, 8-way bursts, spiral and cross attacks.
- **Power-ups** (capsules drop from bricks, caught by the paddle):
  | Letter | Effect |
  |---|---|
  | M | Multi-ball |
  | T | Turret (paddle-mounted shots) |
  | F | Fireball |
  | + | Wider paddle |
  | - | Narrower paddle |
  | S | Shield |
  | B | Barrier |
  | +1 | Extra life |
  | ? | Exit door (see below) |
- **Exit door**: if a level runs 60+ seconds with 3 or fewer indestructible
  bricks left and no life lost, a "?" capsule drops. Catching it opens a
  blinking-arrow exit on the right edge of the playfield, in line with the
  paddle, letting you skip to the next level. A HUD countdown shows the
  60-second timer once it starts.
- Losing a life resets every active power-up (ball/paddle size, shield,
  barrier, turret ammo, fireball).
- Pause (ESC) and level-complete both show big blocky Atari-style text.
- High-score entry is confirmed with Enter only (no mouse-click-away).

## Building

Cross-compiled with the Ubuntu `m68k-linux-gnu-gcc` toolchain, targeting a
real 68000 (`-m68000 -mstrict-align -fno-store-merging`, custom `math.S`
replacements for 68020-only mul/div instructions libgcc would otherwise
emit). A Python-based ELF→Atari PRG converter (`tools/elf2prg.py`) handles
GEMDOS relocation.

```sh
make            # builds build/QUAN.PRG (release) and build/QUANTEST.PRG (autopilot test build)
```

Other targets (`QMICRO.PRG`, `QSNDDG.PRG`, `QEXITA.PRG`, etc.) are
diagnostic/benchmark builds used during development — see the `Makefile`.

`src/main.c`, `src/levels.h`, `src/font.h` and `src/sfx.h` are generated by
the `tools/` scripts (`assemble.py` concatenates the game source, `genlevels.py`
compiles `tools/levels.txt` into brick layouts, `genfont.py`/`gensfx.py`
generate the bitmap font and sound-effect tables) and are rebuilt
automatically by `make`.

## Running

Copy `build/QUAN.PRG` to a TOS-bootable disk image or hard drive folder and
launch it, or run it under [Hatari](https://hatari.tuxfamily.org/) with a
TOS/EmuTOS ROM:

```sh
hatari --tos /path/to/tos.img --auto build/QUAN.PRG
```

## Source layout

- `src/main_head.c` — core types, system-call wrappers, screen/sprite
  primitives, dirty-rectangle rendering
- `src/game_part.c` — game state machine, level/brick/paddle/ball logic,
  power-ups, HUD, `main()`
- `src/boss_part.c` — boss AI, wireframe 3D rendering, attack patterns
- `src/enemy_part.c` — enemy spawning/AI, 8×8 sprite art, pre-shifted sprite
  tables for fast blitting
- `src/ikbd.S` — custom IKBD + Timer C interrupt handler (own mouse/
  keyboard/joystick and sound timing, independent of TOS's own vectors)
- `src/blitfast.S`, `src/gfx.S`, `src/math.S`, `src/sys.S`, `src/crt0.S` —
  assembly blitter, line/rect drawing, 68000-safe math, syscalls, startup

## Hardware target

- CPU: Motorola 68000 @ 8 MHz (real 1040 STFM, no 68020 assumptions)
- Video: 320×200, 4 bitplanes (16 colours)
- Sound: YM2149 (PSG), 3 voices, driven directly rather than through TOS's
  Dosound/Timer C routine
- Input: custom IKBD interrupt handler for mouse and keyboard
